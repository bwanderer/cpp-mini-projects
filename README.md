# C++ Mini Projects

A collection of beginner C++ programs built while learning core programming concepts (loops, functions, conditionals, arrays, and user input handling.)

## Projects

| File | Description |
|------|-------------|
| `rock_paper_scissors.cpp` | Playable RPS game vs the computer with score tracking and replay |
| `num_guessing_game.cpp` | Guess a random number with high/low hints and adjustable range |
| `temp_converter.cpp` | Converts between Celsius, Fahrenheit, and Kelvin |
| `planet_weight_converter.cpp` | Enter your Earth weight and get your weight on any planet |
| `multiplication_table.cpp` | Generates a custom-size formatted multiplication table |

## What it demonstrates

- Functions, switch statements, and loops
- Random number generation (`cstdlib`, `ctime`)
- Input validation and do-while replay loops
- Formatted console output with `iomanip`

## How to run

Compile any file with g++:

```bash
g++ rock_paper_scissors.cpp -o rps
./rps
```

Requires a C++ compiler (g++ or clang++).

## Technologies

C++17 · Standard Library (`iostream`, `cstdlib`, `ctime`, `iomanip`)
